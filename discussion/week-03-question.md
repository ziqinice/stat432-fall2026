I asked an AI agent to download and unzip the Week 3 homework. It created a `week-03` folder at the root of my repository, but the final report needed to be in `homework/week-03/`. I noticed the problem because Git did not list the files in the root folder, and I corrected it by copying the final HTML report to the required location. When a prompt does not name a destination folder, how should an AI agent check the repository structure and choose the correct location before creating files?

Choice. Degree-3 polynomial with C = 0.1 has the lowest mean error (0.268, about 26.8%). Degree 4 with C = 0.1 ties at the displayed precision, so I prefer the lower-degree model. Question 2 | SVM skill applied

One-page analysis report · 11-point body and table text

Data and suitability. This binary classification task has 462 complete rows, nine numeric predictors after family-history coding (Absent = 1; Present = 2), and 160 CHD cases. The sample supports an SVM comparison, although class imbalance makes CHD recall important. A linear kernel tests a simple boundary; RBF allows curvature. I kept this skill run to those two kernels to limit tuning and make selection stable.

Evaluation. Stratified 25% test holdout (seed 432): 346 training and 116 test rows. The 12 settings below were fixed before fitting. On training rows only, I ran stratified five-fold CV three times (seeds 432, 433, 434), re-fitting the scaler in each training fold. Each run reused its folds for all candidates.

Selection and test. The minimum CV error is 0.264 (RBF, C = 10, gamma = 0.01). Its repeat-based one-SE cutoff is 0.273; the simpler linear C = 0.1 model qualifies (CV error 0.270) and is selected. After refitting, test error is 0.259 (30/116). Confusion matrix [actual no/yes × predicted no/yes] = [[65, 11], [19, 21]]. Recall is 85.5% for no CHD and 52.5% for CHD; 19 of 40 CHD cases are missed. This one holdout gives a noisy error estimate and missed cases may be consequential.

# SVM analysis

Use this skill only when the user explicitly names this file. The invocation must supply the dataset, response, predictors, and any required coding.

1. Check sample size, class balance, missingness, predictor types, and whether classification with an SVM is suitable. Explain any exclusions or encoding.
2. Reserve a stratified 25% test set with seed 432. Never use it to choose features, preprocessing, kernels, or settings.
3. Compare a linear kernel as a baseline and an RBF kernel for nonlinear structure. Add a polynomial kernel only when the problem gives a reason; explain the kernel choices.
4. Standardize numeric predictors and encode categories using training data only, refitting preprocessing inside every cross-validation fold.
5. Before fitting, declare the complete candidate grid: linear $C\in\{0.1,1,10\}$; RBF $C\in\{0.1,1,10\}$ and $\gamma\in\{0.01,0.1,1\}$. If polynomial is justified, state its degree, $C$, $\gamma$, and `coef0` candidates in advance and cap the total at 20.
6. On the training set, use stratified five-fold cross-validation with seeds 432, 433, and 434. Reuse each seed's folds for all candidates. Compare mean misclassification rates; also report their variation across repeats.
7. Select the simplest candidate within one standard error of the minimum repeated-fold mean error: linear before polynomial before RBF, then smaller $C$, degree, and $\gamma$. State this rule and the selected settings.
8. Refit once on the full training set. Evaluate once on the reserved test set. Report test error, confusion matrix, and per-class recall; discuss consequential missed cases.
9. Produce a compact figure and table that make the comparison and final choice checkable. Include sample counts, seed, fold design, key numerical results, and limits of the estimate.
10. Put the evidence needed to justify the final model in no more than one printed page at 11-point font. Check the rendered page count; put code and detailed calculations outside that page.
